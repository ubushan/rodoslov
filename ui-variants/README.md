# Варианты интерфейса — тестовые страницы

Пять направлений современного интерфейса Torlmood: по три десктопных макета и
два-три мобильных в каждом. Это макеты, а не рабочий код: чистый HTML + CSS,
без сборки, без React, без базы. Данные вымышленные, но структура настоящая —
те же поля карточки, роли участников, история правок, счётчики и пределы.

## Как смотреть

Откройте `index.html` в браузере (двойной клик по файлу) — там обзор и построчное
сравнение. Дальше — страницы вариантов:

| Файл | Направление | Идея |
|---|---|---|
| `a-quiet-archive.html` | Тихий архив | Типографика и волосяные линии вместо рамок и теней |
| `b-canvas-studio.html` | Холст-студия | Тёмная мастерская: холст во весь экран, стекло, палитра ⌘K |
| `c-family-atlas.html` | Атлас рода | Древо как карта: полосы поколений, путь от корня, ветви |
| `d-card-catalog.html` | Картотека | Плотный указатель: список людей и досье в мастере-детали |
| `e-chronicle.html` | Хроника | Лента времени вместо древа: годы, истории, события — другая пара шрифтов и кислотная палитра |

## Из чего состоит папка

- `SPEC.md` — общий бриф: данные семьи, обязательные экраны, правила, описание
  направлений A–D. `SPEC-E.md` — бриф направления «Хроника».
- `base.css` — общая «рама» страниц: обои документа, браузерная рамка, телефон,
  подписи, чипы, заметки. Интерфейс внутри рамки каждый вариант рисует сам,
  со своим префиксом классов (`va-`, `vb-`, `vc-`, `vd-`, `ve-`).
- `render-shots.sh` — снимки страниц через headless Chrome: полные страницы
  и превью макетов для `index.html`. Запуск: `bash ui-variants/render-shots.sh`.
- `crop-mockups.py` — режет полный снимок на отдельные макеты, чтобы проверять их
  глазами в натуральную величину: `python3 ui-variants/crop-mockups.py <вариант>`.
- `shots/` — превью, которые показывает `index.html` (`*-thumb.png`).
  Остальные снимки — производные, пересобираются скриптом.

## Что важно помнить

- Ничего в `src/` и `public/` не менялось. Папка лежит вне сборки Next.js,
  поэтому при выкатке на прод эти страницы никуда не попадут.
- Шрифты подгружаются с Google Fonts: A–D — Literata и Golos Text, «Хроника» —
  Unbounded, Manrope и IBM Plex Mono. Без интернета макеты откроются системными
  шрифтами — вёрстка не поедет, но вид будет проще.
- Макеты рассчитаны на натуральную величину: десктопный экран 1280×820,
  телефон 390×844. Обзорная страница прокручивается по горизонтали.
