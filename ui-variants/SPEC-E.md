# Бриф: вариант E «Хроника»

Пятое направление интерфейса Torlmood. Дополнение к `ui-variants/SPEC.md`:
данные, общая рама страницы и правила качества берутся оттуда, здесь — только
то, что относится к этому варианту.

## 1. Задача

Сделать направление, **не похожее ни на четыре предыдущих варианта, ни на текущий
интерфейс продукта**. Нельзя опираться ни на их шрифты (Literata, Golos Text),
ни на их палитру (тёмно-синий альбом, латунь, сепия), ни на их композицию
(холст с деревом как главный экран).

Нужен современный, трендовый взгляд: продуктовый, а не архивный.

## 2. Направление «Хроника»

**Смена парадигмы: не древо, а лента времени.** Семья — это поток событий,
разложенный по годам, как лента в музыкальном или фитнес-приложении. Дерево
остаётся, но уходит на вторую роль — отдельной вкладкой.

Ключевые приёмы (это и есть «трендовость»):

- **Год как главный герой.** Крупная цифра года (Unbounded, 52–60px) открывает
  каждую группу событий, рядом — моноширинная подпись с числом событий.
- **Полоса «историй»** — как в соцсетях: кружки с аватарами и градиентными
  кольцами (лайм → коралл), подпись под каждым. Это недавно добавленные
  родственники и свежие события.
- **Карточки-сквирклы**: радиус 20–26px, почти без тени, светлая линия 1px,
  слева цветная иконка категории события. Категории: рождение, брак, переезд,
  служба, фотография, документ, воспоминание — у каждой свой цвет.
- **Липкий рельс десятилетий** слева: 1880-е … 2020-е, у каждого — точка
  плотности событий, активное десятилетие подсвечено лаймом.
- **Бенто-сетка** на обзорном экране: плитки разного размера, мини-график
  прироста рода по десятилетиям, география чипами, «что заполнить», участники.
- **Нижний «остров»** на телефоне: плавающая пилюля-навигация и отдельная
  крупная кнопка действия.

Чего быть не должно: холста с карточками-узлами как главного экрана, скобок пар
и шин между поколениями, «музейной» сдержанности, латунных акцентов, сепии.

## 3. Шрифты

Не пересекаются с прежними вариантами и продуктом. Все три поддерживают кириллицу
(проверено по Google Fonts):

- **Unbounded** (500, 600, 700) — заголовки, годы, крупные цифры.
- **Manrope** (400, 500, 600, 700) — интерфейс и тексты.
- **IBM Plex Mono** (400, 500) — даты, счётчики, метки, годы в списках.

Подключение:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Unbounded:wght@500;600;700&family=Manrope:wght@400;500;600;700&family=IBM+Plex+Mono:wght@400;500&display=swap" rel="stylesheet">
```

## 4. Палитра

Своя, тёмная и насыщенная. Единственное сходство с проектом — что она тёмная.

```
фон            #08080B
поверхность    #101014
поверхность 2  #17171D
линия          rgba(255,255,255,.08)
лайм (главный) #D8FF3E
коралл         #FF6B4A
фиолетовый     #8B5CF6
небесный       #4CC9F0
текст          #F4F4F6
приглушённый   #9B9BA6
```

Градиенты: кольца историй — лайм → коралл; мягкое сияние за крупными цифрами
года (radial-gradient, низкая непрозрачность). Лайм — акцент действий и
активного состояния, больше нигде подряд не использовать.

## 5. Экраны

«Хроника», `p.lead`, `div.chips`; дальше секции `#desktop`, `#mobile`, `#notes`.
Каждый экран — `<figure class="shot">` с `<figcaption><b>название</b>
<code>torlmood.ru/…</code> <span>пояснение</span></figcaption>`.

## 6. Заметки (`#notes`)

Четыре `.note-card`, по правилам `SPEC.md`:

1. «Что это даёт семье» — род читается как история, событие добавляется в три
   касания с телефона, видно, что ещё не заполнено.
2. «Как ложится на код» — конкретно: нужна новая таблица событий (в проекте уже
   есть `tree_events` и `person_changes` — здесь нужен уровень «событие рода» с
   датой, местом, категорией и участниками) и новая страница
   `src/app/(app)/tree/[treeId]/stream/page.tsx`, компоненты
   `src/components/stream/*`, слой `src/lib/stream.ts`; токены — в
   `src/app/globals.css`; Realtime — на таблицу событий; `TreeCanvas.tsx`
   остаётся вкладкой «Древо» без переписывания.
3. «Риски и цена» (`.note-card--warn`) — честно: у большинства семей есть только
   имена и годы, лента быстро вырождается в длинный список и требует дисциплины
   заполнения; тёмная тема на солнце; продукт меняет суть — древо уходит на
   второй план, а это главная ценность сервиса; фото и документы придётся
   показывать в ленте аккуратно, иначе она станет тяжёлой.
4. «Палитра» — `.swatches` / `.swatch` с шестью цветами направления.

## 7. Правила

- Только один файл: `ui-variants/e-chronicle.html`. Ничего больше не создавать
  и не менять: `base.css`, `SPEC.md`, `SPEC-E.md`, `index.html`, `README.md`,
  `render-shots.sh`, `crop-mockups.py` и варианты A–D трогать нельзя.
- Все классы интерфейса — с префиксом `ve-`. Классы `base.css` не переопределять.
- Бренд сервиса — **Torlmood** (латиницей), адреса в макетах — `torlmood.ru/…`.
- Никаких библиотек, растровых картинок и внешних URL, кроме Google Fonts.
  Иконки — инлайн SVG, аватары — CSS-силуэты или инициалы.
- Десктопный `.screen` — ровно 1280×820, `.phone-screen` — 370×824. Внутри рамок
  не должно быть своих полос прокрутки, содержимое не вылезает за края, текст не
  обрезается соседними блоками.
- Данные — из `SPEC.md`, раздел 3. Имена, годы и места настоящие для этого
  набора; выдумывать новых людей нельзя (события вокруг них — можно).
- Типографика: кавычки «ёлочки», тире —, годы `1947–2011` через короткое тире
  без пробелов, цифры табличные (`font-variant-numeric: tabular-nums`).
- CSS — пронумерованными блоками с комментариями. Ванильный JS допустим
  (переключение вкладок, выбор категории), но не обязателен.

Перед сдачей — проверка разметки:

```bash
python3 - ui-variants/e-chronicle.html <<'PY'
from html.parser import HTMLParser
import sys
VOID={'area','base','br','col','embed','hr','img','input','link','meta','source','track','wbr'}
class P(HTMLParser):
    def __init__(s):
        super().__init__(convert_charrefs=True); s.stack=[]; s.err=[]
    def handle_starttag(s,t,a):
        if t not in VOID: s.stack.append((t,s.getpos()))
    def handle_endtag(s,t):
        if not s.stack: s.err.append(f'лишний </{t}> {s.getpos()}'); return
        if s.stack[-1][0]==t: s.stack.pop()
        else:
            for i in range(len(s.stack)-1,-1,-1):
                if s.stack[i][0]==t:
                    s.err.append(f'не закрыты {[x[0] for x in s.stack[i+1:]]} перед </{t}> {s.getpos()}')
                    del s.stack[i:]; break
            else: s.err.append(f'лишний </{t}> {s.getpos()}')
p=P(); p.feed(open(sys.argv[1],encoding='utf-8').read())
print('незакрытые:',[x[0] for x in p.stack]); print('ошибки:',p.err[:10])
PY
```

Ожидаемо: `незакрытые: []`, `ошибки: []`.
