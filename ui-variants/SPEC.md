# Бриф: тестовые страницы вариантов интерфейса

Общий документ для всех вариантов. Читается вместе с `ui-variants/base.css`
(общая «рама» страницы) и `src/app/globals.css` (палитра и токены проекта).

## 1. Что за продукт

**Torlmood** — сервис совместного составления семейного древа (`torlmood.ru`).
Родственники заполняют одно древо вместе: карточки людей, связи поколений,
фотографии и документы, экспорт картинкой, импорт/экспорт GEDCOM, история правок.

Пользователи: владелец древа, редакторы из семьи, зрители. Возраст аудитории —
широкий: от 20 лет до 70+, много работы с телефона. Это **не** рабочий инструмент
генеалога-профи, а семейный архив, который заполняют урывками, вечерами, вместе.

### Сложившийся визуальный язык

Тёмно-синяя «обложка» с латунным тиснением, холодный свет архива, Literata в
заголовках и Golos Text в интерфейсе. Четыре темы: светлая, тёмная, сепия,
«как в системе». Пол человека кодируется цветом: мужчины — `#7fa6c9`,
женщины — `#d1873f`. Латунь `#c9a227` — единственный яркий акцент.

Текущий интерфейс: тёмная шапка → строка с хлебными крошками и действиями →
холст React Flow с плавающей вертикальной панелью слева, легендой справа
сверху, миникартой и кнопками масштаба слева снизу. Карточка человека —
отдельная страница. На телефоне панель свёрнута в одну кнопку с меню,
действия карточки появляются по нажатию, есть нижний лист.

Что уже снято на скриншотах: холст, карточка, шапка, панель, меню аккаунта,
темы, админка, история, фильтр мужской линии.

## 2. Задача

Предложить **четыре разных современных направления** интерфейса вместо
одного текущего. Не косметика, а другой способ смотреть на продукт: другая
иерархия, другие акценты, другой способ добираться до человека.

Это тестовые страницы: чистый HTML + CSS, без сборки, без React, без базы.
Открываются двойным кликом по файлу. Ничего в `src/` не меняется.

Варианты:

| Файл | Название | Идея в одной фразе |
|---|---|---|
| `a-quiet-archive.html` | Тихий архив | Типографика и линии вместо рамок и теней; музейный каталог |
| `b-canvas-studio.html` | Холст-студия | Тёмная мастерская: весь холст, стеклянные панели, командная палитра |
| `c-family-atlas.html` | Атлас рода | Древо как карта: полосы поколений, путь от корня, навигатор-ветви |
| `d-card-catalog.html` | Картотека | Плотный архивный указатель: список + досье, цифры и таблицы |
| `e-chronicle.html` | Хроника | Лента времени вместо древа: годы, истории, события; бриф — в `SPEC-E.md` |

## 4. Обязательная структура страницы

Каждая страница — один самодостаточный HTML-файл. Разметка:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Torlmood — вариант A: Тихий архив</title>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Literata:wght@400;500;600&family=Golos+Text:wght@400;500;600&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="base.css">
  <style>/* только интерфейс этого варианта, все классы с префиксом варианта */</style>
</head>
<body>
  <div class="topbar">…навигация по вариантам, ссылка на index.html…</div>
  <div class="wrap">
    <header class="doc-head">…</header>
    <section class="section" id="desktop">…</section>
    <section class="section" id="mobile">…</section>
    <section class="section" id="notes">…</section>
  </div>
</body>
</html>
```

Верхний блок:
- `p.eyebrow` — «Вариант A»
- `h1` — название
- `p.lead` — 2–3 фразы: чем это направление отличается и кому подходит
- `div.chips` — 3–5 чипов «что меняется» (`<span class="chip"><b>…</b> …</span>`)

Навигация в `topbar`: ссылки на `index.html` и на четыре варианта
(`a-quiet-archive.html`, `b-canvas-studio.html`, `c-family-atlas.html`,
`d-card-catalog.html`, `e-chronicle.html`), текущий — с `aria-current="page"`.

### Экраны

**Десктоп** (три экрана, каждый в браузерной рамке `.frame` → `.screen`):

1. Дашборд — `torlmood.ru/dashboard`
2. Холст древа — `torlmood.ru/tree/kovalevy`
3. Карточка человека — `torlmood.ru/tree/kovalevy/person/arkady`

**Мобильный** (минимум два, в `.phone` → `.phone-screen`):

1. Холст древа
2. Карточка человека

Третий мобильный экран — по желанию, если идея варианта этого требует
(поиск, лента, инспектор). Не больше трёх.

Каждый экран — `<figure class="shot">` с `<figcaption><b>Название</b>
<code>путь</code> <span>пояснение</span></figcaption>`.

Десктопные экраны ставим в `.stage-row` (они широкие, сцена прокручивается
вбок), телефоны — в `.stage-row.stage-row--center`.

### Заметки

Секция `#notes` — блок `.notes` из трёх-четырёх `.note-card`:

1. «Что это даёт семье» — польза человеческим языком.
2. «Как ложится на код» — конкретные файлы проекта: `src/components/tree/TreeCanvas.tsx`,
   `src/components/tree/PersonNode.tsx`, `src/lib/layout.ts`, `src/lib/place.ts`,
   `src/app/globals.css`, `src/components/person/PersonPage.tsx`,
   `src/app/(app)/dashboard/page.tsx`, `src/lib/maleLine.ts` и другие — что
   придётся переписать и насколько глубоко.
3. «Риски и цена» — честно: что станет хуже, что дольше делать, где можно
   промахнуться (`.note-card--warn`).
4. По желанию — «Палитра» с `.swatches` / `.swatch`.

## 5. Технические правила

- **Самодостаточность**: только HTML, CSS и, если очень нужно, пара строк ванильного JS.
  Никаких библиотек, сборщиков, внешних картинок. Аватары — CSS/SVG-силуэты,
  как в проекте (`public/avatars/male.png`, `female.png` — рисовать силуэт
  фигурой, не подключать файл).
- **Никаких растровых вставок**: иконки — SVG инлайном или юникод-символы.
- **Префикс классов**: весь интерфейс варианта — только со своим префиксом
  (`va-`, `vb-`, `vc-`, `vd-`), чтобы не спорить с `base.css` и другими вариантами.
- **Язык**: весь текст по-русски, настоящие имена и даты из раздела 3.
  Никакого lorem ipsum, никаких «Иван Иванов».
- **Типографика**: кавычки «ёлочки», тире —, неразрывный пробел перед тире и в
  «1947–2011» — короткое тире без пробелов. Годы — табличными цифрами
  (`font-variant-numeric: tabular-nums`).
- **Размеры**: десктопный `.screen` — ровно 1280×820, телефон — 390×844
  (внутри `.phone-screen` 370×824). Содержимое не должно вылезать за рамку
  и не должно появляться собственная полоса прокрутки внутри рамки.
- **Контраст**: текст на фоне — не ниже 4.5:1. Интерактивное — не меньше 36px
  по короткой стороне на телефоне.
- **Доступность**: осмысленный порядок заголовков, `aria-label` у иконочных
  кнопок, `:focus-visible` виден, уважать `prefers-reduced-motion`.
- **Ничего вне `ui-variants/`** не создавать и не менять.

## 6. Направления

### A. Тихий архив (`a-quiet-archive.html`) — префикс `va-`

Музейный каталог. Интерфейс уходит в тень, остаются имена и даты.

- У карточек **нет теней и заливки**: белая бумага, рамка 1px `mist-200`,
  радиус 6–8px (не 14). Пол — узкая вертикальная линия слева (2px), не цветной фон.
- Имя — Literata 19px, годы — Golos 12.5px табличными цифрами, место — 12px
  капителью. Никаких аватаров в крупных карточках: только имя и годы.
- Связи — волосяные линии 1px, у сочленений маленькие латунные точки. Пара — тонкая скоба.
- Слева на холсте — **линейка поколений** I–V с засечками и годами эпохи, закреплена.
- Шапка 52px: хлебные крошки слева, действия текстовыми кнопками справа,
  латунная заливка ровно у одного действия («Добавить человека»).
- Дашборд — таблица-список: «Древо · людей · участников · изменено», строки 64px,
  наведение подсвечивает строку целиком.
- Карточка человека — две колонки: «Факты» списком-определениями и «События»
  вертикальным таймлайном с датами слева.
- Мобильный: шапка 48px (название + «…»), линейка поколений — залипающие чипы,
  действия — нижний лист.

### B. Холст-студия (`b-canvas-studio.html`) — префикс `vb-`

Тёмная мастерская: холст занимает всё, обвязка парит над ним.

- Фон холста `#0d131f`, точки сетки еле различимы. Панели — стекло:
  `rgba(25,32,45,.72)` + `backdrop-filter: blur(14px)` + светлая линия 1px.
- Внизу по центру — **док** с иконками: добавить, связь, фильтр, экспорт.
  Справа — **инспектор** выделенного человека (320px) вместо отдельной страницы.
- **Командная палитра** ⌘K: поиск, «найти человека», «добавить», «экспорт»;
  показать её открытой на одном из экранов.
- Карточка — тёмное стекло, кромка 2px по полу, имя Literata 15px, годы моно.
  Выделение — латунная рамка и мягкое свечение; есть мультивыделение со счётчиком.
- Дашборд тёмный: крупные плитки с миниатюрой древа, блок «недавние».
- Карточка человека: инспектор + вкладки «Факты / События / История».
- Мобильный: холст во весь экран, плавающая кнопка «+», пилюля-док снизу,
  инспектор — лист снизу с ручкой, палитра — полноэкранный поиск.

### C. Атлас рода (`c-family-atlas.html`) — префикс `vc-`

Древо как карта, по которой путешествуют.

- Холст разбит на **горизонтальные полосы поколений** — мягкие подложки разного
  тона с подписью слева: «I · 1880–1920».
- Миникарта превращается в **навигатор-ветви**: список ветвей с числом людей
  и кнопкой «перелететь».
- **Поиск с путём**: от корня до найденного человека подсвечивается цепочка,
  остальное приглушается. Это прямой ответ на открытый вопрос журнала —
  «линия от выбранного человека», а не только самый длинный мужской род.
- Хлебные крошки — это путь: `Ковалёвы → Пётр Григорьевич → Аркадий Петрович`.
- Справа — панель «Путь»: шаги с годами и местами, кнопка «показать на холсте».
- Карточки — компактные медальоны: годы слева от имени; выбранный обведён латунным кольцом.
- Дашборд — карта семей и блок «продолжить с того места».
- Мобильный: экран поиска как первый, карточка «Моя ветвь», холст с залипающими
  крошками, путь — лист снизу.

### D. Картотека (`d-card-catalog.html`) — префикс `vd-`

Плотный архивный указатель: всё подписано, всё находится.

- **Мастер-деталь**: слева список людей таблицей 380px (столбцы «Имя · Годы ·
  Поколение · Место», фильтры-чипы, поиск), справа — досье выбранного.
- Цифры моноширинные, годы выровнены в столбец, есть счётчики «148 человек · 61 связь».
- Досье: шапка с именем и годами, «Факты» определениями, «Документы» сеткой
  превью, внизу таймлайн событий и история правок с кнопкой «Откатить».
- Холст — отдельная вкладка «Древо» рядом с «Люди» и «История».
- Дашборд — картотека древ со сводкой (людей, событий, приглашений).
- Мобильный: лента карточек с залипающими фильтрами, досье секциями,
  нижняя навигация из трёх вкладок «Древо · Люди · История».

## 7. Планка качества

Страница должна выглядеть как скриншот живого продукта, а не как схема:

- осмысленный ритм и отступы, выравнивание по общей сетке;
- несколько состояний: выделенная карточка, наведение, активная вкладка,
  бейдж роли, счётчик, пустое состояние или подсказка — где уместно;
- реалистичные подписи: «Владелец», «Редактор», «Зритель», «3 из 10 переходов»,
  «2 часа назад», «12 событий»;
- ничего не обрезано и не наезжает друг на друга; текст не выходит за карточку;
- CSS разбит на пронумерованные блоки с комментариями.

## 8. Как проверять

Перед сдачей:

```bash
cd /Users/ubushan/Documents/AI/rodoslov
python3 - <<'PY'
from html.parser import HTMLParser
import sys
VOID={'area','base','br','col','embed','hr','img','input','link','meta','source','track','wbr'}
class P(HTMLParser):
    def __init__(s):
        super().__init__(convert_charrefs=True); s.stack=[]; s.err=[]
    def handle_starttag(s,t,a):
        if t not in VOID: s.stack.append((t,s.getpos()))
    def handle_endtag(s,t):
        if not s.stack: s.err.append(f'лишний </{t}> {s.getpos()}'); return
        if s.stack[-1][0]==t: s.stack.pop()
        else:
            for i in range(len(s.stack)-1,-1,-1):
                if s.stack[i][0]==t:
                    s.err.append(f'не закрыты: {[x[0] for x in s.stack[i+1:]]} перед </{t}> {s.getpos()}')
                    del s.stack[i:]; break
            else: s.err.append(f'лишний </{t}> {s.getpos()}')
p=P(); p.feed(open(sys.argv[1] if len(sys.argv)>1 else 'ui-variants/a-quiet-archive.html',encoding='utf-8').read())
print('незакрытые:',[x[0] for x in p.stack]); print('ошибки:',p.err[:10])
PY
```

Ожидаемо: пустой список незакрытых и пустой список ошибок.
