# Кликабельный концепт

Самодостаточная HTML-страница со всеми экранами сервиса: главная, вход, список древ,
холст древа, панель карточки, участники и доступ, превью экспорта. Бэкенда нет —
данные живут в памяти страницы.

Откройте `index.html` в браузере или опубликуйте папку через GitHub Pages:
**Settings → Pages → Source: Deploy from a branch → main / docs** (или переименуйте
папку в `docs`).
